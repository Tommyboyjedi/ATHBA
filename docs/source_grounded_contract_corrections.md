# Source authority and bounded contract corrections

This correction uses ATHBA's existing contracts, bounded repair transitions, checklist tree, and language evidence adapters. RackAI remains a generic public workspace executor. Storage assurance, model selection, limits, and routing configuration are unchanged.

## Explicit public operation authority

A required operation expressed in explicit symbolic call notation (for example, "Calling add_item(name, price)") is source authority. ATHBA derives its owner, operation name, ordered parameters, and exact source quote from the original requirement; it never delegates that authority to model-owned public_api prose. The small source parser recognizes explicit calling/method/function/operation declarations with bare symbolic parameters. It uses the existing source provenance/modality rules to exclude optional and forbidden declarations. It does not infer signatures from example constants or free-form prose; conflicting or ambiguous recognized declarations fail closed.

Source deduction must retain each recognized call declaration. Its existing single validation correction handles omissions. Behavior Contract serialization recomputes the signature from original source and rejects altered serialized authority. An approved scenario cannot resume with missing or replaced source signature authority; stale approval fails closed without resetting attempts. Every scenario, including initial state, receives this authority; the frozen scenario carries it to Developer, regression/behavior repair, Intent review and Senior review.

The existing language evidence adapter owns syntax inspection. The Python adapter checks ordinary declared functions and instance methods for exact parameter names/order and rejects extra/default/variadic parameters, unsupported decorators, inherited/dynamic replacement, and asynchronous/positional-only forms. Core coordinators do not parse target language syntax. Unsupported language inspection fails closed. Missing future operations remain permitted during a frontier; final reconciliation requires all recognized operations. Test calls must assign every required parameter exactly once without invented keywords or expansion. This shape proof does not establish behavioral correctness.

Executor acceptance is retained as public execution evidence. ATHBA validates the candidate before trusted revision progression; a signature mismatch consumes the ordinary Developer attempt and retains the untrusted candidate identity. Final and post-behavior Gatekeeper also check the source authority. Naming has no new functional API responsibility.

## Malformed Behavior Planner response

Four Tester submissions still reach the existing Behavior Planner requirement repair route when applicable. A malformed flat response persists the original raw response and exact parser error, then allows one format-only corrective submission using the same required schema and parser. Both responses are durable. A second protocol failure becomes behavior_repair_protocol_exhausted; semantic no-progress, provider failure and an uncertain interrupted submission remain distinct. No fenced/nested normalization, alternate split route, or attempt-count reset is introduced.

## Compound mechanical checklist obligations

The existing policy continues to reject a compound mechanical subject before selecting a verifier. The existing Specification Deducer/checklist split route may now partition such a failed constraint or quality item. Children must partition every conjunct exactly once, retain the same full parent source quote, kind and modality, and route independently to an existing bounded verification policy. Disjunction, dropped/invented conjuncts or an independently unverifiable child fails closed through the existing bounded validation repair. The compound parent is superseded only after a valid grounded split; no verifier partially approves it.

## Context reduction

A Tester repair packet retains candidate source and feedback once when the repository excerpt or feedback is exactly duplicated. The other field becomes an explicit reference to the retained field. Unequal context and durable evidence stay intact; task paths, tools, acceptance, semantics and budgets are unchanged. Retained campaign feedback gives a conservative measured saving of 1,409 UTF-8 JSON bytes over ten immediate repair packets. This measures duplicate context, not tokens or execution speed.

## Deferred storage assurance

The operator requested that TemperatureTracker storage analysis remain unchanged pending clarification of a smaller, largely language-agnostic design. No Python-specific owned-container/storage analysis expansion is included. The retained storage failure remains an assurance coverage limit, and the three-scenario campaign remains gated on the unresolved targeted storage proof.
