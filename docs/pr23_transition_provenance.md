# PR23 typed transition provenance

Session 8B3B2A makes every strict-TDD feature advance carry an immutable `StrictTddTransitionPath`. The path contains the feature transition and, only when the feature is consuming a scenario transition, the exact scenario transition and optional exact microcycle transition. It is a compact boundary object: it does not embed feature, scenario, or microcycle state. Impossible shapes fail closed: a microcycle must be nested beneath `MICROCYCLE_ADVANCED`; `MICROCYCLE_ADVANCED` must name its microcycle; and planning, contract, gatekeeper, selection, behavior recording, reconciliation, and completion cannot claim nested work. A blocked feature can retain nested scenario provenance for the transition that caused the terminal result.

`ScenarioAdvanceResult` exposes its `microcycle_kind` and deterministic-regression effect flag. The feature application copies those values and the external-reasoning/Rack AI flags directly into its result and its complete transition path. It never recovers them by interpreting a status or evidence string. The behavior-completion feature advance keeps the completed behavior pending and returns `SCENARIO_ADVANCED`; only the next advance returns `BEHAVIOR_RECORDED`, without inherited nested provenance or effects.

`StrictTddCheckpointPolicy` is a pure typed policy. `RED_FRONTIER_ACCEPTED` maps only to `FRONTIER_RED_ACCEPTED`; the one-time first-regression checkpoint maps only to `CANONICAL_BASE_PROMOTED` and the supplied typed previous-checkpoint set; and pre-review scenario checkpoint maps only to `SCENARIO_COMPLETED`. `StrictTddTerminalPolicy` chooses continue, checkpoint, blocked, or completed from typed transition kind/path, availability, blocker, and explicit requested checkpoint.

`StrictTddTransitionEventProjector` is also pure. Given a run context, typed feature transition, and caller-supplied occurrence it returns lifecycle event drafts only. Its event id is a SHA-256 of run id, full path, stable transition fingerprint, and occurrence, so it uses neither time nor persistence. It carries project/behavior/scenario/frontier/canonical/working/candidate facts where available and creates `transition:<kind>:<stable-fingerprint>` evidence when a transition has none. Event kind mapping is exhaustive and keyed directly by typed enums. The projector imports no repository or sink and performs no external effect.

No controller, CLI, live endpoint, Rack AI source/configuration, ReservationBook proof, or PR21 work is included in this phase.
